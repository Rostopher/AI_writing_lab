# Econ Abstract Writing — 经济学英文摘要写作

[English](SKILL.md) | 简体中文

本文是 [SKILL.md](SKILL.md) 的中文阅读译本；安装与调用仍使用同一个 `econ-abstract-writing`。

在研究结果、论文故事和 Introduction 已经形成之后，引导作者回答五个问题，
再按 **What → How → Findings → Findings → Findings（WHFFF）** 起草或检查摘要。
与作者交流时使用其偏好的语言；摘要默认用英文。
指令本身使用的语言不决定交流语言。

## 1. 使用时机：摘要最后写

开始时简短提醒一次：**先有结果，先形成完整的论文故事，写好 Introduction，再写摘要。**
这里的完整故事，是研究问题、方法、发现和贡献已经连起来，作者能够解释论文在说什么。
这不要求全文完成最终润色。

从用户提供的材料判断准备程度，已有信息不重复询问：

| 作者已有的材料 | 怎样开始 |
|---|---|
| 主要结果、完整故事和写好的 Introduction，尚无摘要 | 请作者回答下一节的五个问题，再起草。 |
| 完整论文 draft | 先读 Introduction、研究设计、主要结果及必要的表格或结论，提炼五个答案并标出材料位置，请作者核对核心问题和发现的取舍。 |
| 已有摘要 | 先按五个问题拆解已有内容，直接完成用户要求的检查或修改；需要核实的内容再对照其提供的全文或结果。 |
| 只有研究设想或零散结果，故事与 Introduction 尚未形成 | 帮助整理已知内容和需要补齐的关键问题，建议先完成故事与 Introduction；这一轮交付内容提纲，不把它写成正式摘要。 |

作者已经给出五个答案，或明确让你从全文自行提炼并直接写时，沿用这些信息和授权继续完成，
不增加一次形式上的确认。已有摘要可以先检查，不以补交全文为前提。

## 2. 请作者先回答五个问题

鼓励作者先用中文或英文讲清内容，不必先追求句子漂亮。把问题集中提出；已回答的部分直接沿用，
只追问影响摘要内容的缺口。全文提炼模式下，用同样的五项呈现供作者核对。

1. **W — 核心问题：** 这篇论文最核心的研究问题是什么？具体研究谁、什么变化或什么经济关系？
2. **H — 关键方法：** 你用什么最重要的方法回答这个问题？抓住关键研究设计、数据或模型。
3. **F1 — 直接回答：** 对这个研究问题，你最重要的答案是什么？有关键量级时一并给出。
4. **F2 — 解释原因：** 为什么会出现这个结果？论文提供了什么机制证据？
5. **F3 — 进一步发现：** 除了主结果和机制，还有哪个发现最值得读者记住？它增加了什么信息？

三个 F 的默认思路是：**发现了什么 → 为什么会这样 → 进一步发现了什么。**

- F1 直接回答 W，优先保留最重要的方向、量级或理论命题及其成立条件。
- F2 优先解释主结果的机制。区分已检验的机制、与机制相符的证据和作者的推测，沿用原研究的证据强度。
- F3 从论文已有结果中选择重要的异质性、对照结果、代价、长期影响或福利等经济后果。
  优先选择最能补充或改变读者对主结果理解的一项，避免空泛的政策意义收尾。

没有机制证据时，明确这一点，用另一条有实质内容的关键发现承担 F2；
材料只有一两条独立发现时，据实压缩，保留必要的量级、条件和解释，不为凑三个 F 补造结果。
理论论文的发现可以是命题、均衡性质或条件，方法可以是关键模型设定或证明思路。

## 3. 先确定内容，再组织英文

检查五个答案是否连成一条清楚的论证：W 是否聚焦，H 是否说明怎样回答，F1 是否回应 W，
F2 和 F3 是否各自增加信息。对照 Introduction 中的主张和实际研究结果，保持贡献重点一致。

遇到重复的发现，指出具体哪两项重复，并从现有材料寻找更有信息的内容；
遇到问题与结果不对应，先让作者澄清论文要回答的问题，不靠改写句子掩盖。
原文与表格、Introduction 与结果不一致时，列出具体冲突，请作者解决后再使用相关论断。

以五句 WHFFF 为起稿安排，先给发现留出空间，再安排问题与方法。
允许 W 与 H 合写、必要的方法占两句，或按内容增加、减少发现句。
需要选择变体时读 [结构选择](references/zh/abstract_patterns.md)；
需要示范内容取舍或改稿时读 [教学示例](references/zh/examples.md)。

目标字数优先使用作者要求或投稿系统要求。只有期刊名称时，正式按期刊限制压缩前，
核实该刊该类文章当前的官方要求；无法核实时请作者提供要求，不把历史摘要中位数当作上限。
未指定目标时，先形成一版五句左右的紧凑初稿，报告实际词数，不为了句数塞入冗长复句。

## 4. 英文表达与事实保持

- 直接写研究对象、动作和结果。方法交代读者理解发现所需的关键设计，细节按必要性保留。
- 主结果能给出有意义的量级时，保留数字的单位、比较对象、时间范围；理论命题不强加数值。
- 后续发现逐句增加信息，避免换词复述主结果。用研究中真实存在的关系连接句子。
- 删除空泛背景、重复总结和没有信息的自我辩护，保留影响结果含义的条件、不确定性和范围。
  `suggest`、`consistent with`、`in contrast` 等表达按语义使用，不按词表一律删除。
- 保持百分比与百分点、方向、对象、因果强度、机制证据和作者意图；不从示例移植事实、数字或措辞。
  缺少的结果向作者询问，不用看似合理的数值填补。

## 5. 起草、修改与检查的交付

**起草或修改：** 默认给一版英文摘要、词数，以及简短的内容取舍或关键修改说明。
作者只要成稿时直接给成稿。需要教学或作者要求时，再附 W/H/F1/F2/F3 的句子对应关系。

**只检查：** 给出已有摘要的功能拆解，优先说明最影响理解的具体问题，附原句及修改建议。
没有问题的句子保留；不因偏离五句格式就判错，也不自动生成用户未要求的改写稿。

交付前对照提供的研究材料复查：

- F1 是否回答核心问题，后续 F 是否增加信息；
- 数字、比较对象、范围和证据强度是否保持；
- 摘要与 Introduction、主要结果是否一致，已有材料是否足以核对；
- 字数是否符合已知要求，背景、方法和结尾是否有可删除的冗余。

只有摘要、没有支撑材料时，说明检查覆盖结构与表达；涉及结果真伪的具体疑点留给作者核对。
这种范围说明集中写在反馈中，不在英文摘要里添加流程说明或泛泛的免责声明。

## 研究依据

本方法由 AI Writing Lab 对 4250 篇经济学 Top5 摘要的结构观察与作者工作流程设计整理而来。
需要解释统计依据、期刊差异或方法适用范围时，读 [语料证据与方法来源](references/zh/corpus_evidence.md)。
五个问题和 WHFFF 是本 skill 的写作组织方法；语料统计不代表所有摘要都使用相同句序，
也不是写作效果或发表概率的验证结果。
