# AI Tone Check — 减少 AI 写作痕迹

把「AI 味」拆成可观察的问题再动手，不做凭感觉的整体改写。

## 问题清单（七类可观察维度）

1. **套话**：空泛表达与高频 AI 词（delve、foster、leverage、 genuinely、"it's worth noting"；值得注意的是、综上所述、赋能、助力……）
2. **重复总结**：结尾套话（"Bottom Line:"、"In short:"、"The simplest mental model is:"；总而言之、由此可见）
3. **机械结构**：对比框架（"This isn't about X. It's about Y"、"X, not Y"、"X—not Y"）、自问自答（"Why does this matter? Because..."）、不仅……更……、首先/其次/最后八股
4. **不必要修饰**：生造连字符复合词（"exact-head checks"）、空泛限定词、罐头过渡
5. **空泛判断**：无证据、无数字、无具体对象的断言（正则抓不住，靠判断）
6. **缺少具体信息**：该有名字、数字、例子的地方只有形容词（靠判断）
7. **作者声音不一致**：段落间口吻忽人忽机、详略失衡（靠判断）

## 工作流程

### 第一层：确定性扫描

词表与句式正则，命中精确位置。Python 可用时运行：

```bash
python scripts/scan.py <目标文件>
# 或管道输入
cat draft.md | python scripts/scan.py -
```

脚本零依赖（纯标准库），输出每个命中的行号、类别、原文片段与分类统计，支持 `--json`。
词表在 `wordlists/` 下（`en_slop.txt`、`zh_slop.txt`），纯文本一行一条，用户可自行增删；
`re:` 前缀表示正则，否则按字面匹配（英文单词自动加词边界）。

Python 不可用时，用编辑器/grep 按词表手工搜索同样的条目。

### 第二层：语义判断

扫描覆盖不了的维度，逐条检查：

- 每个论断是否有证据、数字或具体对象支撑？（空泛判断）
- 关键处是否该出现具体信息却只有形容词？（缺少具体信息）
- 全段是否都在重复开头说过的话？（重复总结）
- 段落口吻是否前后一致？（作者声音）

### 输出报告

按类别列出：命中位置 → 原文 → 判断（真问题 / 文体偏好）→ 改写建议。
**命中 ≠ 错误**：先区分「跨场景成立的 AI 痕迹」和「该文体的正常表达」，
领域术语、作者有意为之的修辞不列入修改。

## 改写原则（来自官方建议）

- 主旨前置：先把结论说清楚，再展开支撑。
- 每段一个主旨，句子承接上文推进，不绕回重复。
- 用朴素动词和介词直接陈述关系，不用生造复合标签和连字符堆砌。
- 主动语态、直接陈述；不引入读者没问的对比（"X, not Y"）。
- 不预告「我不做什么」「哪些保持不变」，直接做事。
- 保留作者的声音与领域术语，只去除空转的表达。

## 边界

- 本 skill 检查的是**表达层**，不评价观点与论证质量。
- 中英词表都在持续积累中；发现漏网的高频 AI 腔，直接补进 `wordlists/`。
