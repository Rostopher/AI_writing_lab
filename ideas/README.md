# Ideas

想法孵化区：未定型的 research ideas、proposal、写作假设与实验设计。

## 内容类型

- 研究 proposal（如：某类论文如何建立贡献声明、如何组织论证）
- 写作假设与检验设计（claim → 需要什么证据 → 最小验证）
- 贡献定位草稿、方法论草图
- 被否掉 / 搁置的想法（留档避免重复）

## 每个想法至少回答

- **Claim**：想证明什么
- **Why it matters**：为什么值得做
- **Evidence needed**：需要什么数据、文献、实验或表格
- **Minimum viable test**：最小可行验证
- **Paper shape**：成功后进入论文 / 报告哪一部分
- **Failure modes**：什么会让它不成立

## 边界

- 稳定项目事实 → `memory-docs/`
- 已消化知识 → `notes/`
- 面向读者的正式文本 → `manuscripts/`
