# Modules — academic_writing（学术写作）

论文表达侧实现：规划、起草、修订与审核，服务于把研究证据组织成论文。

## 职责

- 论文结构规划（建立背景 → 提出问题 → 推进论证 → 回应替代解释 → 安排证据与限定）
- 学术写作的领域规则：贡献声明、引用支持、因果限定、方法透明
- 起草、修订与审核的实现

## 与 academic_research 的关系

- `academic_research`：研究内容定位 + 论文组织方式的认识（输入侧）
- `academic_writing`：把上述认识落实为论文文本（输出侧）

两者共享受众 / 结构 / 论证的判断逻辑；先各自推进，相似性经验证后再上移公共层。
