# Modules — academic_research（学术研究）

当前主线的第一个推进方向：从期刊数据形成**研究内容上的定位**与**论文表达与组织上的认识**。

## 职责

学术方向的文献调研、问题定位、期刊案例分析。从期刊数据库的 thorough 调研可以产生两种成果：

1. **研究内容定位**：已有研究解释了什么、还有什么争议、什么证据不足、
   我们的问题与贡献处在什么位置。
2. **论文表达与组织认识**：某类论文如何建立背景、提出问题、推进论证、
   回应替代解释、安排证据与限定。

## 边界（重要原则）

- 从已发表论文观察到的写作特征，可用于**提出和检验写作假设**；
  但不能仅靠论文确认「某种写法就是期刊青睐它的原因」。
- 研究问题、设计、证据质量与表达方式交织：观察到的相关性 ≠ 被青睐的原因。
- 「顶刊中反复出现的组织方式」（观察）与「已验证有效的写作建议」（证据）
  **分开记录**，避免从模仿文章滑向模仿表面措辞。

## 数据依赖

- 期刊数据由 `playwright_crawler` 采集维护
- 经 `paper-workspace` 物化为 `papers/` 下的论文工作区
