# Modules — writing_pipeline（预留）

通用写作流程模块：**规划 → 起草 → 修改 → 审核**的跨场景实现。

## 状态：预留（不预建实现）

按「先允许差异、后提取共性」原则，本模块**不提前抽象**。当前判断：

- 学术写作与商业写作都需要「确定受众 → 整理证据 → 规划结构 → 起草 → 审核」的骨架，
  但学术论文（贡献声明、引用支持、因果限定）与商业报告（决策建议、执行条件、行动指引）
  的判断规则不同，需各自的领域专属实现。
- 当同一机制在两个方向都被实际需要、且接口趋于稳定后，再上移到这里。

## 触发生成的信号

- 两个以上方向出现了结构一致的起草 / 修订 / 审核逻辑，且差异可参数化
- 需要被独立安装、发布或调用（此时可能拆为独立仓库）
