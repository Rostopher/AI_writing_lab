# 这篇博客怎么写：编辑思路

对应正文：[摘要写了五句话，几句在讲你的发现？](econ_abstract_blog.md)

## 文章的主张

把研究发现写充分。用4250篇顶刊摘要提供三个层次的支持：发现占多少篇幅、通常出现在哪些位置、为什么会连续写好几句发现。读者最后能据此动手改自己的摘要。

正文采用用户选定的经济学风格：黑白灰、衬线字体、简洁坐标。正文配图只保留图表主体、坐标、图例和分面标签，并按实际内容收紧留白。图1—4的图题写在Markdown图片下方，统计说明与来源另列Notes；原来的五套风格比较稿继续保留。

## 标题和开头

正文标题采用「摘要写了五句话，几句在讲你的发现？」。读者能立刻拿自己的摘要来回答；副标题给出4250篇顶刊摘要，交代这篇文章的证据来源。

如果发布平台只展示一个标题，我更推荐：

**分析4250篇经济学顶刊摘要：请给研究发现留够篇幅**

另有两个备选：

- **你的摘要给研究发现留了几句话？我们分析了4250篇经济学顶刊论文**
- **经济学论文摘要怎么写：五句话，先把发现讲清楚**

开头让读者打开自己的摘要、标出发现句，然后立刻给出49.4%。研究缘起、模型配置和分类细节向后放，避免读者要读几屏才能知道文章对自己有什么用。

## 证据怎样变成写作指导

| 段落 | 读者得到什么 | 用到的证据与图 |
|---|---|---|
| 篇幅 | 写初稿时，先替发现留出足够空间 | 49.4%的平均文本占比；正文图1 |
| 位置 | 五六句话怎样分工；结果何时开始展开 | 五句、六句摘要的位置分布；正文图2；五句起草表 |
| 衔接 | 方法后面接什么，发现为什么要连续展开，怎样收尾 | H→F 57.0%、F→F 59.4%、Y→END 73.6%；正文图3 |
| 示例 | 把上述安排落实为一段英文 | 明确标为虚构的职业培训研究，附五句功能拆解 |
| 期刊 | 对齐目标期刊的实际空间 | 各刊词数和句数；正文图4 |
| 改稿练习 | 当天就能改一遍摘要，或作为给学生的小作业 | 先写三个发现，再补问题和方法，附四个检查问题 |

这轮补了正文图1的「文本篇幅占比」。原有的功能覆盖率图展示的是「多少篇摘要出现某功能」，其中98.2%与49.4%是不同指标。新图直接对应文章的核心发现，读者更容易看懂。

正文保留完整转移矩阵，并给读者清晰的阅读入口：方法→发现、发现→发现、意义→结束。各格子的细节供感兴趣的人继续看。篇幅分配、连续报告发现、最后一句的用途，这三部分彼此推进。

## 给导师一个自然的转发理由

文章末尾的练习可以直接布置给学生。学生提交修改后的摘要和逐句功能标注，导师据此讨论结果是否写充分、结构是否顺畅。

适合转发时附的一句话：

> 写摘要前可以看这篇。它分析了4250篇经济学顶刊摘要，讲清楚五六句话怎样安排，重点是把研究发现写具体。建议按文末的练习改一版，再把每句话的功能标出来。

文章的传播点放在可操作的内容上：49.4%这个容易记住的发现、一张五句起草表、三个转移概率、一个能照着做的练习。老师转发时有明确用途，学生收藏后也有再次打开的理由。

## 语气和写法

直接说数据里有什么，接着说读者可以怎样改。建议落在动作上：圈出发现、报告量级、压缩方法、补充关键结果、重写末句。用具体的研究对象和例子解释这些动作。

正文不铺设假想争论，不反复自我辩护，不使用固定的转折对比句式，也不把每一节都写成一段结论加三条口号。必要的样本和计算说明集中放在图注、文末数据说明。

## 已核实的数字与表达

- 「方法只占一句」调整为「方法常涉及一两句」。全量报告中How触及1句、2句的摘要分别为1504篇、1338篇；Findings主要为2—4句，Why主要为0—1句。
- 五句和六句合计46.5%；加上四句为65.5%。正文写「五句最多」「四到六句合计65.5%」。
- 49.4%是逐篇计算后取平均的文本占比，98.2%是包含发现的摘要比例。两个数字分开解释。
- 五句摘要第3—5句的Findings出现率为68.9%、80.9%、69.9%；末句Why出现率为19.4%。
- 六句摘要第4—5句的Findings出现率为75.2%、81.3%。
- 转移矩阵中的73.6%是当前主功能为Why时接END的比例。正文没有将它写成以Why结尾的摘要占比。
- 五句起草表作为练习安排呈现，未声称这是样本中占多数的完整序列。实际完整序列统计保留在源数据中。
- 英文职业培训案例及数字为教学自拟；正文在示例前明确说明。

证据入口：[全量报告](../../notes/data/abstract_structure_full_report_v03.md)、[聚合统计](../../data/processed/abstract_structure/run_20260909_v03_full/v03_full_tweet_aggregates.json)。原要点清单把「单一最高频路径不超过7%」写得过宽：四句类的H-F-F-F已达13.4%。本文未采用该概括。
