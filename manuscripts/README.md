# Manuscripts

正式写作区：本项目自身产出的论文、研究报告与写作样本分析。文本面向读者（而不仅是
个人理解）时移入这里。

## 建议布局

```text
manuscripts/draft/      完整草稿
manuscripts/sections/   章节 / 模块化草稿
manuscripts/figures/    图表与图表说明
manuscripts/appendix/   附录
manuscripts/archive/    已废弃 / 旧版本
```

## 边界

- 论文的阅读笔记 → `notes/paper-reading/`；研究设计草稿 → `ideas/`。
- 目标期刊的语料分析是研究材料（`papers/`），不是本项目手稿。
- 尚未面向读者的不稳定脑暴不进入本目录。
