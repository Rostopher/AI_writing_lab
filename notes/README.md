# Notes

研究理解层：把文献、案例和工具消化为**可复用的研究知识**。这里放笔记，不放原材料。

## 子目录

- `paper-reading/`：文献阅读笔记——论文真正回答的问题、核心 claim 与边界、
  数据/方法/指标、对学术方向的用途（支持/反驳/方法/定位/引用）、外推限制
- `methods/`：写作方法拆解（如何建立背景、提出问题、推进论证、回应替代解释）
- `data/`：数据源理解与字段口径说明
- `concepts/`：写作概念框架（受众、声音、论证结构、评价维度）
- `pipelines/`：参考仓库 / 工具 pipeline 的复现说明

## 规则

- 笔记是**消化后的判断**，不是摘抄：记录「一句话结论 → 为什么记 → 核心内容 →
  对本项目的影响 → 证据与来源 → 不确定性 → 下一步」。
- 跨场景写作研究与参考工具分析也在这里，按主题归入对应子目录。
- 自由记录优先，不强求一开始就套完整模板；整理成稳定 note 是可选项。
- 从论文观察到的写作特征与「已验证有效的写作建议」分开记录，避免把相关性当因果。
