# Ideas

## Purpose

Idea incubation layer for claims, proposals, contribution positioning, alternative designs, and failed or parked ideas.

## What Belongs Here

- Research proposals
- Core claim iterations
- Methodology sketches
- Contribution positioning
- Critiques and alternative designs
- Minimum viable tests

## What Does Not Belong Here

- Stable project facts
- Raw literature dumps
- Final manuscript prose
- Executable pipeline code
