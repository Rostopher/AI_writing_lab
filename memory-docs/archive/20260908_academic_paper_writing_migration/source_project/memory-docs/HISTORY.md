# Project History

## 2026-09 — 从写作技巧收集转向可评价的研究项目

项目起点不是再做一个语法润色器，而是同时研究论文整体思路、与既有文献的定位、
section/段落/句子的功能，以及具体用词、句式、语法和论证强弱。首轮审计发现，
`revise-paper` 提供了完整论文修订与判断权限协议，但没有 benchmark；
`NaturePanelForge` 虽然处理科学图表，却提供了阶段产物、独立审核、validity gate 和
分维度报告等可迁移机制。因此项目先建立多层分析框架和 evaluation proposal，
把 rubric 与人类一致性验证放在自动 evaluator 和 AI 应用之前。
