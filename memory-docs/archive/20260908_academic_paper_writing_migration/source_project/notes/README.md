# Notes

## Purpose

Research understanding layer: paper reading notes, method notes, data notes, concept notes, and pipeline reconstructions.

## What Belongs Here

- `paper-reading/`: free-form but useful paper notes
- `methods/`: method and measurement notes
- `data/`: data-source and variable understanding
- `concepts/`: conceptual frameworks
- `pipelines/`: repo, benchmark, or data pipeline explanations

## What Does Not Belong Here

- Raw PDFs and OCR outputs
- Formal manuscript sections
- Executable scripts
- Large datasets
