# Manuscripts

## Purpose

Formal writing layer for paper drafts, chapters, appendices, figure captions, response notes, and submission-facing text.

## Suggested Layout

```text
manuscripts/draft/
manuscripts/sections/
manuscripts/figures/
manuscripts/appendix/
manuscripts/archive/
```

## What Belongs Here

- Introduction drafts
- Related work drafts
- Method and results sections
- Appendix text
- Figure and table notes
- Referee response drafts

## What Does Not Belong Here

- Raw reading notes
- OCR outputs
- Data-processing scripts
- Unstable brainstorming that has not become paper-facing
