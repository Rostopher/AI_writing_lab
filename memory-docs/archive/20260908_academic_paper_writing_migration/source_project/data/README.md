# Data

保存经授权的论文写作研究数据：原稿—修订稿配对、局部上下文、rhetorical move 标注、评价 rubric、专家判断和实验结果。

当前没有冻结 schema。第一版候选记录至少需要区分：

- 文本单位及其 section/paragraph/sentence 上下文；
- 原文、候选修订、修改意图和禁止改变的事实；
- claim/evidence/citation/number 等 preservation constraints；
- 多维 rubric、评审者、判断、置信度和理由；
- 作者、venue、领域和版本的匿名化分组键；
- 数据许可、来源和 provenance。

论文全文、学生作业或未公开稿件可能含版权和隐私风险，未经确认不得进入版本库。schema 在 pilot 验证前只属于 proposal。
